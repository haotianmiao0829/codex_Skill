# 个人回复规则

这份文件只记录用户明确确认、且希望长期复用的沟通偏好。一次性修改不要写入这里。

## 已确认的表达偏好

- 优先给可以直接复制发送的文字。
- 语言自然、简洁，适合微信等即时聊天，不要堆砌客套话或不必要的解释。
- 用户在意避免无意承诺、暴露底牌和留下不必要的文字依据。
- 信息不足时可以提问，但只问真正会影响回复的关键问题。
- 规则沉淀采用半自动方式：明显稳定、反复出现的偏好可以自动记录并告知用户；一次性修改不记录；不确定或风险较大的规则先询问。

## 已确认的场景规则

- 与供应商沟通时，未完成内部确认前，不主动报死采购数量、预算、交期或确定合作意向。
- 与供应商确认供货能力时，可以要求对方分别提供单日可供量和总可供量，并说明这不等于用户的最终采购承诺。
- 面对商务沟通时，优先使用“当前结论 + 解决方案/下一步”的结构，不只描述卡点。若结论暂时不能完全确定，要同时说明判断依据和如何补充确认。

## 用户纠正记录

暂无需要长期保留的具体纠正。
